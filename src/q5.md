# Question 5 — Operating Systems, Terminals, and Shells

**Format:** Short Answer

---

> Answer in your own words, 1-3 sentences each. Writing it yourself is the point.


**(a)** What is a **kernel**, in plain language? (One or two sentences. No textbook definition copied in; explain it as you understand it.)

**Answer:**
_(A kernel is the core background program that controls everything on a computer. It acts like the engine that communicates with the software and hardware components of a computer.)_

---

**(b)** A classmate says:

> "I installed WSL, so now I have two completely separate operating systems, Windows and Linux, running side by side, each totally independent."

Is this accurate? Briefly explain why or why not.

**Answer:**
_(No it is not accurate. WSL allows a windows user to use Linux OS within a virtual machine on the windows computer. It is not independent because it relies on the windows hardware.)_

---

**(c)** Explain the difference between a **terminal (emulator)** and a **shell**, and give one example of each.

**Answer:**
_(The terminal is just the visual window where you type commands whereas the shell is the engine behind the terminal that actually processes the commands and gives the output back to the terminal to display. An example of a terminal is Windows Terminal and an example of a shell is Windows PowerShell.)_
